# ska_hist (описание исходного сайта)

Сайт «Отечественная история» К. А. Соловьёва для студентов. Статический сайт, раньше жил на Wix (без VPN не открывался), теперь на GitHub Pages.

Вопросы по работе сайта: Telegram [@qddwxd](https://t.me/qddwxd).

## Как устроено

- `*.html` — готовые страницы. Их **не правим руками**, они генерируются.
- `tools/build.mjs` — генератор: меню, разделы, дизайн страниц, лекции, объявления.
- `data/pages.json` — тексты страниц, выгруженные из Wix.
- `data/editable/*.json` — текущие тексты страниц группы 107 и курсовых; имеют приоритет над выгрузкой Wix.
- `data/assetmap.json` — соответствие ссылок Wix локальным файлам.
- `assets/style.css`, `assets/app.js` — оформление и меню.
- `files/` — презентации (.pptx) и PDF. `img/` — картинки.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run build   # пересобрать страницы
npm run serve   # посмотреть на http://localhost:8080
npm test        # проверки HTML, вложений и локального сервера
```

## Что где менять

| Задача | Где |
| --- | --- |
| Внешний вид | `assets/style.css` |
| Меню и разделы, адреса страниц | `NAV` в `tools/build.mjs` |
| Страницы группы 107 и курсовых | вкладка «Страницы» в `admin.html` или `data/editable/*.json` |
| Текст остальных страниц | `data/pages.json` |
| Новая лекция | через `admin.html` или положить файл в `files/` с именем `lekciya-N.pptx` (диапазон лекций определяется автоматически) |
| Журнал баллов | вкладка «Баллы» в `admin.html` или `data/journal.json`; правила оценок — `assets/journal-core.js`; сервер для самостоятельного ввода — `worker/README.md` |
| Новое объявление | через `admin.html` или добавить запись в `data/announcements.json` |

После правок: `npm run build`, проверить в браузере, закоммитить вместе с пересобранными `.html`.

## Дизайн: 3D-Москва и откат на прежний

По умолчанию сайт собирается в 3D-оформлении: фон — Красная площадь на Three.js (`assets/scene/`).
На главной камера при прокрутке летит от здания к зданию: Спасская башня, колокольня Ивана Великого,
Покровский собор, МГУ, Исторический музей, ГУМ. На страницах раздела камера подлетает к «его» зданию
и входит в палату с росписью. Если 3D недоступно или включено «уменьшение движения», показывается тот же текст без анимации.

| Что | Где |
| --- | --- |
| Здания площади | `assets/scene/world.js` |
| Палата внутри | `assets/scene/interior.js` |
| Камера, прокрутка, переходы | `assets/scene/scene.js` |
| Оформление поверх сцены | `assets/scene/scene.css` |
| Какой раздел к какому зданию | `SECTION_SCENE` в `tools/build.mjs` |

**Вернуть старый дизайн:** `SITE_DESIGN=classic npm run build` — страницы получаются точно такими же, как до 3D.
Для сайта на GitHub: Settings → Secrets and variables → Actions → Variables → `SITE_DESIGN` = `classic`.
Чтобы вернуть 3D, удалите переменную. Последний коммит до 3D-дизайна: `b77792c`.

## Публикация

GitHub Actions собирает актуальные данные из `main` и публикует артефакт через `actions/deploy-pages`. Источник Pages — **GitHub Actions**. В публичную папку входят только HTML, `assets/`, `files/`, `img/`. Данные и генератор остаются в репозитории для разработчиков. После правок преподавателя HTML в checkout может быть старым: выполняйте `npm run build`, источником текста являются JSON-файлы.

## Как преподаватель добавляет материалы сам

Преподавателю не нужен ни GitHub, ни установка программ. На сайте есть страница `admin.html` (в меню не показывается) с формами «добавить лекцию» и «добавить объявление» и страница `instrukciya.html` с инструкцией для него. Ему нужен только **ключ доступа**, который выдаёте вы.

Как это работает: страница через GitHub API кладёт файл в `files/` или правит `data/announcements.json`, `data/lectures.json`, `data/editable/*.json`. Workflow `.github/workflows/build.yml` пересобирает и публикует страницы, обычно за 1–5 минут. Пересобранные страницы не коммитятся ботом: публикация происходит непосредственно из артефакта.

### Лимиты

- Файл не больше 50 МБ (ограничение GitHub API).
- Лекции именуются автоматически: `lekciya-N.pptx` (ФГУ), `mehmat-lekciya-N.pptx`, `speckurs-lekciya-N.pptx`.
- На вкладке «Страницы» можно менять задания, расписание, итоги и другие страницы ФГУ и все четыре страницы курсовых. Сохраняются оформление, списки, ссылки, таблицы и картинки; можно прикреплять документы.
- Таблицы со старого Wix перенесены как картинки. Их можно заменить снимком или таблицей из Word/Excel.
- При одновременных изменениях сохраняющий запрос использует SHA загруженной версии: конфликт не перезаписывает чужую правку. Текст остаётся в редакторе.
- Программа и разделы Мехмата/Спецкурса пока правятся в `data/pages.json`.
